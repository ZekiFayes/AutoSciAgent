# Task 02: 2D Transient & Steady-State Orthotropic Heat Conduction

## Governing 2D PDEs
1. **2D Transient Orthotropic Formulation**:
   $$k_x \frac{\partial^2 T}{\partial x^2} + k_y \frac{\partial^2 T}{\partial y^2} = \rho c_p \frac{\partial T}{\partial t}$$
2. **2D Steady-State Orthotropic Limit ($\partial T / \partial t = 0$)**:
   $$k_x \frac{\partial^2 T}{\partial x^2} + k_y \frac{\partial^2 T}{\partial y^2} = 0$$
